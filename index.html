What this tool does
It re-encodes your video to a consistent vertical 1080×1920 MP4 target using FFmpeg in WebAssembly. It can improve consistency and reduce unnecessary export variables, but it cannot recreate detail that was never present in the source.
No backendNo databaseLocal browser processingMP4 output
Why can processing be slow?
FFmpeg runs in WebAssembly on the device. Longer videos, higher quality settings and weaker phones require more CPU/RAM.
Does this make a low-quality video true 4K?
No. Upscaling or re-encoding cannot create genuine source detail that is not present in the original video.
Why does the first load take time?
The browser downloads the FFmpeg WebAssembly engine once so the encoding can happen locally.
